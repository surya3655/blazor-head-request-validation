## Existing .NET 10 → .NET 11 upgrade — details

- **Scope:** Validate an existing .NET 10 Blazor app (local) and its behavior after upgrading and building under .NET 11.
- **Expected:** After upgrade, the app builds under .NET 11 and HEAD/GET return matching statuses for pages (for example `/plain` returns 200 for both HEAD and GET).
- **Current / Result:**
	- Original .NET 10 app (observed):
		- `GET /plain` → `200 OK` (see: [artifacts/ExistingNet10/existing10.txt](artifacts/ExistingNet10/existing10.txt))
		- `HEAD /plain` → `404 Not Found` (see: [artifacts/ExistingNet10/existing10.txt](artifacts/ExistingNet10/existing10.txt))
		- Note: historical repro expected `405 Method Not Allowed` for similar HEAD requests on .NET 10; this run showed `404` for `/plain` which still represents a HEAD/GET mismatch.
	- Upgraded (.NET 11) app (observed):
		- `GET /plain` → `200 OK` (see: [artifacts/ExistingNet10/existing11.txt](artifacts/ExistingNet10/existing11.txt))
		- `HEAD /plain` → `200 OK` (see: [artifacts/ExistingNet10/existing11.txt](artifacts/ExistingNet10/existing11.txt))
	- Overall: **PASS** — upgrade to .NET 11 resolved the HEAD/GET mismatch for the tested route.

- Product issue: Streaming HEAD semantics — `HEAD /slow` returns before component async work completes. FAIL in all tested configurations (Static SSR, Interactive Server, Container Static, Container Interactive). Evidence: `artifacts/*/slow.timings.txt`.

## Failed test cases — details

- `/slow` (streaming)
	- **Expected:** `HEAD` and `GET` should report the same status and comparable timings; `HEAD /slow` should not return before server-side streaming work completes (GET ~4s).
	- **Current:** `HEAD /slow` returns quickly (~0.004s) while `GET /slow` runs the expected ~4s streaming operation. This mismatch caused the `/slow` scenario to FAIL in all configurations.
 	- **Timing command used:** `curl -s -o /dev/null -w 'status=%{http_code}\ntime=%{time_total}\n' -I <url>` (the harness writes `status` and `time` into `*.head.timed.txt` and `*.get.timed.txt`). Note: avoid `curl -X HEAD` for this test — it can hang in some environments; prefer `-I` plus `-w` to measure timing.
	- **Evidence:**
		- Static (local): [artifacts/head-validation-static-20260824/slow.timings.txt](artifacts/head-validation-static-20260824/slow.timings.txt)
		- Interactive (local): [artifacts/head-validation-interactive-20260824/slow.timings.txt](artifacts/head-validation-interactive-20260824/slow.timings.txt)
		- Container (static): [artifacts/container-run-20260825-162850/slow.timings.txt](artifacts/container-run-20260825-162850/slow.timings.txt)
